# CE Web Browser v5.0.0

🚀 为 Slay the Spire 2 打造的内置浏览器插件

## 功能特性

- **完整浏览器UI** - 现代化的界面设计，包含导航栏和状态栏
- **导航历史** - 前进、后退、刷新和主页按钮
- **收藏夹管理** - 添加、删除和快速访问收藏的网站
- **响应式布局** - 自适应不同面板尺寸的灵活界面
- **拖拽调整大小** - 自由移动和缩放浏览器面板
- **透明度调节** - 自定义面板透明度，不干扰游戏
- **外部浏览器回退** - 跨平台支持，自动选择合适的浏览器打开方式
- **快捷站点** - 预设常用网站快速访问
- **跨平台** - 支持 Windows、Linux 和 macOS

## 编译说明

### 前置要求
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Slay the Spire 2 游戏（版本 0.105.0 或更高）

### 编译步骤

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/it71/trysljjt2web.git
   cd trysljjt2web
   ```

2. **设置游戏目录路径**
   
   编辑 `WebOverlay.csproj` 文件，将 `Sts2Dir` 设置为你的 Slay the Spire 2 游戏安装目录：
   ```xml
   <Sts2Dir Condition="'$(Sts2Dir)' == ''">C:\Path\To\SlayTheSpire2</Sts2Dir>
   ```
   
   或者在编译时通过命令行参数指定：
   ```bash
   dotnet build -p:Sts2Dir="C:\Path\To\SlayTheSpire2"
   ```

3. **编译项目**
   ```bash
   dotnet build -c Release
   ```

4. **获取编译输出**
   
   编译成功后，DLL 文件将生成在 `bin/Release/net8.0/` 目录中。

### 项目依赖

项目依赖以下游戏 DLL 文件（位于游戏安装目录的 `data_sts2_<平台>/` 文件夹中）：
- `GodotSharp.dll`
- `sts2.dll`
- `0Harmony.dll`

## 安装说明

### 使用预编译版本
1. 下载最新版本的插件
2. 将插件文件放置在游戏的 mod 目录中
3. 在游戏中启用插件

### 使用自行编译版本
1. 按照上述编译说明编译项目
2. 将编译生成的 DLL 文件和 `WebOverlay.json` 放置在游戏的 mod 目录中
3. 在游戏中启用插件

## 使用指南

### 基本操作
- 打开/关闭浏览器面板
- 在地址栏输入网址并点击 "前往" 按钮
- 使用导航按钮（前进、后退、刷新、主页）浏览网页

### 收藏夹功能
- 点击收藏按钮保存当前页面
- 在收藏夹列表中点击项目快速访问
- 选择项目后点击删除按钮移除收藏

### 界面设置
- 拖动标题栏移动面板位置
- 拖动右下角调整面板大小
- 使用透明度滑块调节面板透明度
- 切换紧凑/完整视图模式

### 快捷键
- 在外部浏览器中打开当前页面
